    Trigger API

    The scene only reacts to triggers. Send triggers from the buttons, the keyboard, or your backend.

    // 1. Same page
AEGIS.trigger('spawn',   {kind:'wasp', count:2})
AEGIS.trigger('attack')                    // all hostiles fire a volley
AEGIS.trigger('damage',  {part:'L1', amount:50})
AEGIS.trigger('repair')                    // or {part:'A3'}
AEGIS.trigger('upgrade', {id:'flank'})
AEGIS.trigger('retreat') | ('reset') | ('demo')
AEGIS.trigger('log',     {text:'Agent rule v12 deployed', level:'ok'})
AEGIS.trigger('say',     {text:'Shields holding.'})
AEGIS.on('*', e => console.log(e))         // listen to sim events

// 2. Another tab or iframe
new BroadcastChannel('aegis').postMessage({type:'spawn', payload:{kind:'leech'}})
window.postMessage({aegis:true, type:'repair'}, '*')

// 3. Backend over WebSocket: open index.html?ws=ws://localhost:8787
//    then send JSON frames: {"type":"spawn","payload":{"kind":"warden"}}

    Keys: 1-4 spawn, W wave, A volley, X retreat, R repair, U upgrade, D demo, P pause, M mute.
